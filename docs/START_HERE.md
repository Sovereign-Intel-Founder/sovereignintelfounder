# Start Here: Sovereign Intelligence Protocol (SIP)

Welcome to the Sovereign Intelligence Protocol repository. This guide provides a rapid architectural overview for engineers and auditors reviewing the system.

## Repository Map

* **`docs/`**: Central architecture guides, proof indexes, and verification maps.
* **`prototypes/`**: Core experimental harnesses, protocol routines, and test fixtures.
* **`README.md`**: Top-level project summary and quickstart notes.

## Key Principles

* **Absolute Transparency:** Every architectural design and benchmark claim is backed by explicit code paths or server telemetry metadata.
* **Low-Latency Focus:** Designed around atomic SPSC ring buffers, core pinning, and microsecond performance targets.
* **No Bloat:** Ephemeral virtual environments, full raw logs, and sensitive keys are strictly excluded from version control.
