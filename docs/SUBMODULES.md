# Submodule Architecture & Boundaries

The Sovereign Intelligence Protocol (SIP) repository incorporates auxiliary submodules and independent projects. Absolute boundaries are maintained:

1. **Sovereign Seed Commons:** Maintained as an entirely separate project repository. It is **not** merged into SIP.
2. **sovereign-intelligence:** Houses independent protocol components and reference bindings.
3. **clean-check:** Auxiliary repository used for validation and workspace integrity checking.
