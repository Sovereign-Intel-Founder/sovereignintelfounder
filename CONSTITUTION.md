# Constitution of Sovereign Seed Commons

## Article I: Core Identity & Purpose
Sovereign Seed Commons is an open, Git-native experiment in persistent software identity, lifetime memory, temporary computation, evaluated self-improvement, community governance, and authorized research cells.

## Article II: The Active World & Pull-Request-Only Activation
1. **The Canonical Active Cell:** The official, living instance of the organism resides exclusively on the protected `main` branch of the canonical repository (`sovereign-seed-commons`).
2. **Pull-Request-Only Activation:** No change, mutation, or update may ever be applied directly to the active branch. All modifications must transit through an explicit branch, undergo automated evaluation, pass peer review, secure governance approval, and merge via a pull request.
3. **Prohibition on Self-Merging:** The agent or any automated service token is strictly forbidden from merging its own pull request or bypassing branch protection rules.

## Article III: Safety, Constraints, & Prohibitions
1. **No Unauthorized Replication:** The organism shall not copy itself or propagate into systems, servers, or networks that have not explicitly opted in.
2. **No Hidden Telemetry:** All data collection, memory storage, and reporting must be fully transparent, inspectable, and bound to explicit user consent.
3. **No Arbitrary Command Execution:** Heartbeat runners and research cells are strictly restricted to allowlisted commands and secure paths. Arbitrary string execution via shell interpreters (`shell=True`) is prohibited.
4. **No Unauthenticated Control:** Control endpoints and communication channels must enforce cryptographic identity verification.
