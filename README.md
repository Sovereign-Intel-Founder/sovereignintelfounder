# Sovereign Intelligence Protocol (`sovereignintelfounder`)

High-performance, low-latency infrastructure built for deterministic execution, strict auditability, and verifiable telemetry.

---

## 📂 Repository Architecture

* `01-core-systems/` — Bounded ingestion pipelines, ring buffers, and tollbridge core logic.
* `02-low-latency/` — Hardware optimizations (AF_XDP, POSIX shared memory, NUMA affinity).
* `03-verification-security/` — Conformance suites, protocol verifiers, and security harnesses.
* `04-benchmarks-evidence/` — Reproducible telemetry runs, CSV/JSON outputs, and manifests.
* `05-prototypes/` — Experimental modules, protocol v1 builds, and mesh prototypes.
* `06-experiments/` — R&D sandboxes, hardware stress-testing, and failed approaches.
* `docs/` — Architecture specs, component status, and [EVIDENCE_INDEX.md](docs/EVIDENCE_INDEX.md).
* `archive/` — Historical and legacy code versions.
